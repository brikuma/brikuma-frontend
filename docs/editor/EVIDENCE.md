## Local performance baseline

[The repeatable runner](../../scripts/editor-performance.mjs) used Chrome 153.0.8010.53, reported `ANGLE Metal Renderer: Apple M2`, 1440×900 CSS pixels, DPR 1, Auto/conservative quality, loopback static output with no CPU/network throttle. A fresh browser context measured empty activation; later scene switches were warm. Fixture source hashes, build identity, actual counts and measurements are in the JSON. This is a local lab result, not a claim about all hardware or every 5,000-piece model.

Shell observation was 146.8 ms from the runner's navigation start; the first real frame was 550.0 ms and scene-ready 552.8 ms on the page performance clock. The first Add/Place task took 178.8 ms including automation/DOM overhead. These are separate observations, not one combined readiness metric.

Median active orbit intervals were 16.7 ms. A strict 16.67 ms ceiling was not uniformly met; all observed p95 intervals stayed below 33.3 ms. The latency proxy records the next render submission, not displayed pixels or real-user INP. Fewer samples than clicks occur when no new frame is needed; sample denominators are retained rather than treating missing samples as zero.

Actual drag-preview cancellation took 159.7 ms and preserved revision/identity/count/position/history. Completed drag took 157.2 ms, moved `added-1` from X=0 to 0.5 studs and added exactly one history transaction. Undo took 39.4 ms and restored the exact prior model. Those task durations include automation and assertions; they are not continuous pointer latency measurements.

All three scenes added zero frames in the measured settled idle interval. Twenty alternating empty/courtyard resets stabilized at 15/24 geometries and 6 textures; a selected courtyard adds one expected outline geometry. This establishes observed GPU-resource count behavior, not a complete JavaScript heap/listener leak proof. The headless background attempt reported `document.hidden=false`, so that run does not establish true background behavior. A supplementary isolated headed Chrome attempt on the preceding renderer-identical build (`artifacts/editor/background-check.json`) also retained `hidden=false`; native zoom key attempts did not change viewport width/DPR. Neither is counted as a hidden-tab or native-zoom pass.

Initial editor JavaScript is approximately 234.6 KiB gzip, CSS 8.5 KiB, and all noninitial JavaScript together approximately 413.8 KiB (a conservative upper bound for lazy 3D). No font bytes are downloaded; geometry is original procedural data rather than external model assets. Exact values and poster sizes remain in the budget report. No current field LCP/INP/CLS, representative mobile network profile or human task outcomes were measured.

## Review, limits and next action

Independent source review identified and verified resolutions for Space-pan focus, assembled restoration, revision-counter overflow, unaccepted-proposal export, export camera refitting, invisible selection outlines and comparison labels after returning to Build. Browser verification then checked the fixes. The exact staged reviewer and candidate are recorded through the existing gate before the authorized child commit. Root integration remains separately blocked by absent approved remotes; no synthetic gitlink, push or deployment is included.

Original geometry uses nominal dimensions and explicit approximations, with no manufacturer approval or physical certification. Supported rectangular connectors/material volumes remain separate from unknown decorative geometry. Candidate choices use bounded world distance and manual selection, without a claim of automatic screen-space magnetic snapping. Translation and quarter-turn manipulation are implemented; arbitrary-angle/axis gizmos and adaptive quality are not. Reference planes are optional and not shipped; local image boards/manual scale declarations are. Curated steps use a shared isometric restore rather than per-step camera authoring. PNG output is bounded square framing.

**EDR-029 is blocked** by absent verified hinge geometry/pivot/axis/range metadata. **EDR-031–036 are deferred P2**. The usability protocol (EDR-030) and automated local baseline exist, with **zero human participants**. Firefox runtime coverage, native zoom, real touch/trackpad and screen-reader checks remain gaps. The next smallest interaction risk is real-device gesture arbitration; dense connector/diagnostic query cost also needs a separate workload beyond these rendering measurements.
