# Third-party notices and provenance

No project-wide open-source license has been selected; this document does not grant one. Retain upstream dependency license files in installed packages and preserve verbatim notices when distributing required third-party source/assets.

The exact dependency/license review belongs to [dependency evidence](docs/engineering/DEPENDENCIES.md). Asset provenance belongs to [reference and asset register](docs/references/README.md). Original deterministic demo models, interface compositions and generated previews are project-authored. Demo identifiers do not claim catalog verification.

Typography currently specifies a system-sans fallback until an exact Manrope asset and its license are acquired and verified. No remote font service is necessary. Do not claim a downloaded font license was reviewed when no font was acquired. No LDraw subset, official instruction scan or official brand asset is authorized by the implementation brief.

If shadcn source is copied, record the exact registry/component/version/source, preserve required upstream notices and review code changes on updates; auditing dependencies alone cannot inspect copied component code.

The static export includes [third-party license and notice text](public/THIRD_PARTY_LICENSES.txt), generated by [the notice collector](scripts/licenses.mjs). It conservatively includes installed nonoptional production dependencies and nested upstream notices; it does not mean every listed package is loaded in the browser. Platform-specific native dependencies are excluded from this static notice collection because their binaries are not distributed in `out/`.

Where an exact published package omits a separate license file, the generator retains its declared license, exact manifest and available README verbatim rather than inventing copyright attribution. Fiber9.8.1 and Draco1.5.7 upstream notice files are preserved from verified source commits; [source URLs and hashes](public/third-party-licenses/provenance.json) record provenance. Metadata-only declarations are printed by `npm run licenses:generate`; package redistribution beyond this static POC requires a renewed packaging review. `npm run licenses:check` rejects a stale generated notice file.
